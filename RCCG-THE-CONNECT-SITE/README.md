
# Modern Church Platform

## Setup Commands

```bash
npx create-next-app@latest church-platform
```

Choose:
- TypeScript → Yes
- ESLint → Yes
- Tailwind CSS → Yes
- App Router → Yes

## Install Packages

```bash
npm install framer-motion lucide-react react-icons
```

## Run Development Server

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

## Start Production Server

```bash
npm start
```
